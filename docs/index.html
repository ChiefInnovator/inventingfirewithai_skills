The behavior you want by default.

The skill blends Karpathy-style caution with Torvalds-style pragmatism, then adds the discipline modern coding agents need.

Evidence First

Read relevant code, docs, and tests. Distinguish observed results, conclusions from inspection, assumptions, and untested behavior.

Little or No Code

The best developers avoid unnecessary code. The skill rejects unrequested features, ceremony, and speculative abstraction.

Verified Changes

Choose tests, builds, runtime checks, or visual inspection according to the change and risk. Finish with relevant checks and a final diff review.

Data First

Simplify data within compatibility constraints. Use interfaces for meaningful boundaries and document contracts where they matter.

Surgical Edits

Touch required lines, preserve behavior, avoid adjacent cleanup, and keep parallel work in disjoint areas.

Cost Aware

Respect the user's model choice and optimize total cost to a verified result. Reassess failed approaches before escalating.

Install a complete skill folder.

Copy a complete skill folder from skills/codex/ or skills/claude/ into the matching client’s skills directory, including bundled scripts and references. For GitHub Copilot, copy a folder from skills/copilot/ into your repository’s .github/skills/.

Invoke $skill-name in Codex or /skill-name in Claude Code and GitHub Copilot. In Copilot CLI, run /skills reload after installation. Each package’s SKILL.md explains its supported workflow and required tools.

Questions about the skills.

What is an AI agent skill?
A skill is a reusable folder of task instructions in SKILL.md, plus any references, scripts, or assets its workflow needs. These packages guide an agent inside your chosen client and project.
Which clients does this library support?
All five skills have packages for Codex, Claude Code, and GitHub Copilot. Choose the matching client folder above and install the entire folder so its supporting resources remain available.
What changed in Travel Like a Local?
It asks for destination and dates only when they affect the decision, uses brief onboarding for personalized planning, and keeps private traveler preferences separate from the shared skill. Saving preferences requires consent. Its test evidence includes four offline Codex behavioral scenarios.
Can I install the travel ZIP directly in ChatGPT?
The Travel Like a Local ZIP is a complete Codex skill source archive, not an installable plugin package. A local skill installation does not establish availability in ChatGPT. See the web setup status and verification checklist.
Does a Figma conversion mean production approval?
No. Capture, Flutter rendering, pixel comparison, human review, and production integration are separate results. The generic skill adapts to the target project’s architecture and design system; a conversion request does not authorize shipping or publishing designs. Read the Figma workflow and validation scope.
What license covers the library?
The repository is shared under the MIT license. Follow the target project’s instructions and the client’s permission rules when using a skill.
