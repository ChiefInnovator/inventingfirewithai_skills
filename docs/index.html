The behavior you want by default.

The skill blends Karpathy-style caution with Torvalds-style pragmatism, then adds the discipline modern coding agents need.

Evidence First

Read relevant code, docs, and tests. Distinguish observed results, conclusions from inspection, assumptions, and untested behavior.

Little or No Code

The best developers avoid unnecessary code. The skill rejects unrequested features, ceremony, and speculative abstraction.

Verified Changes

Choose tests, builds, runtime checks, or visual inspection according to the change and risk. Finish with relevant checks and a final diff review.

Data First

Simplify data within compatibility constraints. Use interfaces for meaningful boundaries and document contracts where they matter.

Surgical Edits

Touch required lines, preserve behavior, avoid adjacent cleanup, and keep parallel work in disjoint areas.

Cost Aware

Respect the user's model choice and optimize total cost to a verified result. Reassess failed approaches before escalating.
