The behavior you want by default.

The skill blends Karpathy-style caution with Torvalds-style pragmatism, then adds the discipline modern coding agents need.

No Guessing

Read code, docs, and tests before deciding. State assumptions, choose, proceed, and verify.

Little or No Code

The best developers avoid unnecessary code. The skill rejects unrequested features, ceremony, and speculative abstraction.

Verified Changes

Public-interface tests, preconditions, security checks, performance budgets, and targeted validation replace hand-wavy claims.

Data First

Fix data shape before adding conditionals. Use interfaces only for real seams and contracts.

Surgical Edits

Touch required lines, preserve behavior, avoid adjacent cleanup, and keep parallel work in disjoint areas.

Cost Aware

Use the cheapest model likely to verify the work, then escalate when complexity or failures justify it.
